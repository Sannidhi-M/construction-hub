# Known `tsc --noEmit` errors for apps/storefront that scripts/check.sh accepts.
# One error per line as printed by tsc, without the (line,col). Currently empty:
# every error fails the check.
#
# History: this file used to list ~300 harmless "'Heading' cannot be used as a
# JSX component" style errors. Cause: two copies of the React TYPES in one
# compile (@types/react 18 at the repo root, which hoisted libraries such as
# @medusajs/ui resolve, and the storefront's own @types/react 19), so the two
# ReactNode types were "unrelated". Fixed by the `react` / `react-dom` entries
# in tsconfig.json `paths`, which make every import of React resolve to the
# storefront's one copy of the types. Do not remove them. If a new dependency
# ever brings the errors back, check that it still resolves React through
# those entries before adding anything here.
